01

Purpose

The project investigates how web development can create a more interactive digital museum experience and make historical artworks feel more engaging to explore.

02

Technology

HTML structures the pages, CSS creates the visual identity and responsive layout, while JavaScript controls a searchable twenty-four-work collection, rooms, modals, hotspots, tours, speech, local progress, user testing and workshop tools.

03

User experience

The interface is designed to feel cinematic without hiding the navigation. Interaction, readable information, keyboard support and mobile behaviour are developed together.

04

Main risk

The biggest risk is making the project too large for one person. The final prototype therefore uses one reusable interaction system across twenty-four artworks instead of building every room separately.

USER TESTING

How will “better experience” be evaluated?

The final version should be tested by several users. Their feedback can be used to evaluate whether navigation is clear and whether hotspots, the audio guide and the workshop actually make the artworks more interesting and understandable to explore.

PROBLEM → SOLUTION

Development decisions.

01 / AUDIO

From a visual button to a real guide.

The first audio controls were only visual. JavaScript was added for play, pause, resume, stop, status and progress, with slower sentence-by-sentence narration, a live transcript and automatic support for studio MP3 recordings when they are added.

02 / MOBILE

Navigation could not disappear.

The desktop links originally vanished on smaller screens. A keyboard-accessible mobile menu was added so all four pages remain reachable on phones and tablets.

03 / SCOPE

Reusable systems instead of copied pages.

The collection expanded to twenty-four works, but every artwork uses the same data-driven room, hotspot, narration, inspection, favorites and Night Passport systems. This keeps the project scalable.

USER TEST PROTOTYPE

Turn the question into measurable feedback.

This local testing tool stores anonymous responses only in this browser, calculates live summary statistics and can export the results as CSV for the report. Nothing is sent to a server.
